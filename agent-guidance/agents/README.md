# Agent guidance (non-Cursor)

App-specific instructions live in **`AGENTS.md`** at the repository root.

| Task | Skill |
|------|--------|
| Add a feature page | `.agents/skills/ssa-feature-page/SKILL.md` |

**Cursor users:** use `.cursor/skills/` and `.cursor/commands/` instead (same skill content).

**NGUI component catalog:** `AGENTS.ngui.md` (from `@cigna/cigna_dae_ngui_library` postinstall).

Source of truth for editable guidance: **`agent-guidance/`** — synced on `npm install` via `scripts/sync-agent-guidance.js`.

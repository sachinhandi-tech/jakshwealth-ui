Setup

  1. Install Python dependencies and start FastAPI on port 8010. Commands are in jakshwealth-api/kite_app/README.md.
  2. Start this UI with npm start from jakshwealth-ui.
  3. Open the Kite login link for your API key and sign in with the Zerodha client ID saved on the app.
  4. Copy request_token from the redirect URL. It works only once.
  5. Submit this form. The next screen is your dashboard.

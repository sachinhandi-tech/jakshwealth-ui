Setup

  1. The desk calls the deployed Kite Lambda. It does not use a server on this PC.
  2. Open the Kite login link for your API key and sign in with the Zerodha client ID saved on the app.
  3. Copy request_token from the redirect URL. It works only once.
  4. Submit this form. The next screen is your dashboard.
